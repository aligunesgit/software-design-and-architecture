# Project Sprint A

Week 6

Dedicated project work. No new lecture content this week; apply Modules 1-5 to your own group
project.

## Goals

* Group formed, system domain chosen, short design brief written
* Project repository scaffolded with a clear package structure
* At least one deliberate SOLID-aligned refactor, before and after documented
* At least two design patterns applied where they genuinely fit
* An explicit architectural style chosen and justified in writing
