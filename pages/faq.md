## What are the prerequisites for this course?

At least 1 year of general programming experience, comfortable reading and writing
object-oriented code, basic data structures and algorithms. No specific language is required;
every code example in the course is in Python, but the ideas are language-agnostic.

## Can I use ChatGPT, Copilot, or other AI tools for the exercises, the project, or the report?

Yes, but treat them as a tool, not a substitute for understanding. Validate anything an AI tool
produces before relying on it, and write your report answers in your own words, since the report
is meant to describe *your own* project work and decisions.

## Do I need to know Python specifically?

No. Every code example in this course is in Python for readability, but the principles and
patterns are language-agnostic. If your project is in another language, the same patterns and
architectural reasoning apply; only the exact syntax changes.
