# Summary of course content

This page maps each major concept or tool taught in the course to the module it belongs to.

| Concept / tool | Role | Module |
|---|---|---|
| Quality attributes, technical debt | Framing for the whole course | M1 |
| SOLID principles | Object-oriented design | M2 |
| Coupling, cohesion | Design quality measures | M2 |
| Factory, Builder, Singleton, Adapter, Decorator, Facade | Creational and structural patterns | M3 |
| Strategy, Observer, Command, Template Method, State | Behavioral patterns | M4 |
| Layered, MVC, event-driven, pipe-and-filter architectures | Architectural styles | M5 |
| Domain-driven design, bounded contexts, aggregates | Modular design at the domain level | M6 |
| Microservices, service boundaries, API design | Distributed decomposition | M7 |
| CAP theorem, retries, circuit breakers, timeouts | Distributed systems resilience | M8 |
| C4 model, UML, Architecture Decision Records | Architecture documentation | M9 |
| ATAM-style evaluation, code complexity metrics, refactoring | Quality evaluation | M10 |
